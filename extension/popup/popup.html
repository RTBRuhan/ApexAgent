Technical detail

Approve this connection

A program on this computer wants to see and control this browser: your open tabs, the pages you are signed in to, and what you type. Only approve it if the code below matches.

The same six digits are printed in your editor's MCP log. If they do not match, or you were not expecting this, choose Reject.

Exactly what approving does

Approving sends the code back to the local server, which then hands this extension a token stored in extension storage. From then on the connection is re-established without asking you again. The code expires after two minutes, and three wrong codes drop the connection. To undo it later, run apex-agent pair --reset or delete ~/.apex-agent/token; the next connection will ask you again.
