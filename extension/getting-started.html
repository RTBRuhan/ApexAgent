Apex Agent

Set up in five minutes

Apex Agent lets the AI assistant in your code editor work in this browser — the real one, with your logins and your open tabs. Five steps, in order. Each one gates the next, so do not skip ahead.

Before you start

  • Node.js 18 or newer. Check with node --version in a terminal.
  • An editor that speaks MCP: Cursor, Claude Code, or Codex CLI.
  • This extension installed in Chrome. If you are reading this page from the extension, that part is done.

1

Install the extension

From the Chrome Web Store, or load it yourself from a copy of the repository:

  1. Open chrome://extensions.
  2. Turn on Developer mode, top right.
  3. Choose Load unpacked and select the extension folder.
  4. Pin Apex Agent to the toolbar. The panel behind that icon is where you will see whether any of this is working.

2

Get the server running

A small program on your computer sits between your editor and this browser. Pick one of two routes. Most people want the first.

Route A — nothing to install

Use the published package

The config in step 3 runs npx -y apex-agent-mcp for you, and npx downloads the package the first time it is needed. You do not have to run anything by hand. If you want to watch it start, or check that Node can reach the registry, run it once yourself: 

npx -y apex-agent-mcp

It stays in the foreground and waits for a browser. Press Ctrl+C to stop it; your editor will start its own copy.

Route B — from a clone

Run it from the repository

Use this if you are changing the server yourself.

git clone https://github.com/RTBRuhan/ApexAgent
cd ApexAgent/mcp-server
npm install
Do not skip npm install. The server imports packages that are not in the repository, so running node index.js before installing them fails with ERR_MODULE_NOT_FOUND and no other explanation. Earlier versions of this guide left that step out, and this is the error it produced.

On this route your editor config points at the file instead of the package: use node as the command and the full path to mcp-server/index.js as its only argument.

When something is wrong

      

        The panel always names one state. Find that state here.
      

      


      

        
It says Connected, but nothing happens

        

          Either the master switch is off or the capability that request needs is off. Both cases
          refuse the request and tell your editor so — check the panel's activity list, which will
          show the request as not allowed.
        


        
ERR_MODULE_NOT_FOUND when the server starts

        

          You are on route B and npm install has not been run in
          mcp-server. Run it there, then restart your editor.
        


        
Two editors are open and only one seems to work

        

          Both are attached; they just may be pointed at different tabs. The panel lists each editor
          with the tab it will act on, and lets you point one at the tab you are looking at.
        


        
The chat panel that used to be here is gone

        

          It was removed in version 2, along with any API key it had stored. Your editor does that
          job better, and the panel had a flaw in how it displayed replies. Apex Agent now works only
          through your editor.
